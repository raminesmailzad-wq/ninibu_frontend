YekanBakh FaNum font assets are not distributed with this project.
Place your licensed font files in this directory using these names:

Required for APK:
- YekanBakhFaNum-Regular.ttf
- YekanBakhFaNum-Bold.ttf

Optional:
- YekanBakhFaNum-Medium.ttf

If Medium is not present, Ninibu automatically uses the Regular FaNum family for medium text.
Run from the repository root:
  pnpm mobile:prepare-font
  pnpm mobile:apk-check
