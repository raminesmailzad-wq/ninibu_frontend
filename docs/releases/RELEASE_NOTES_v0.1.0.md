# Ninibu Frontend v0.1.0

## Scope
- Monorepo foundation with pnpm workspaces + Turborepo.
- Next.js App Router web application.
- Ninibu brand tokens based on the approved purple/pink logo palette.
- Animated splash screen using the approved logo asset.
- OTP authentication against Ninibu Backend.
- Web BFF session layer with HttpOnly access/refresh cookies.
- Session restore and automatic refresh path.
- First-login onboarding: parent profile -> residence -> first child -> complete.
- Country/province/city APIs connected to backend v0.22.2.
- First Home shell and main product navigation cards.
- Shared packages prepared for the future Expo/React Native app.

## Backend expectation
Designed against Ninibu Backend v0.22.2 contracts.
