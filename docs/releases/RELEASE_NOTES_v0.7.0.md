# Ninibu Frontend v0.7.0

## Profile & Family Management

This release makes Profile a working management surface using the existing Backend v0.22.2 contracts.

- Parent profile editing.
- Residence editing with country/province/city dependency.
- Family overview and active-child switch.
- Add-child form.
- All user-visible date values are Jalali/Persian.
- Date-only values sent to the backend remain Gregorian `YYYY-MM-DD`.
- All forms open as centered modals; the Jalali Date Picker opens as a higher nested modal.
