# Frontend v0.16.0 — Native Expo Mobile

This release keeps the complete web frontend and adds `apps/mobile`, a native React Native/Expo client intended for real-device development through Expo Go. It shares API/type/design/validation/datetime packages with web but uses direct bearer-token API access and SecureStore instead of the web BFF cookie model.

The mobile feature surface includes auth, onboarding, dashboard, family/children, health/growth, community, discovery/search, services, consultations, bookings, commerce, notifications, profile and advertising consent.
